# Introduction

Version: 1.0.0

---

## Purpose

The purpose of this Software Requirement Specification is to clearly define the complete functionality of the GoTaxi platform before development begins.

The document ensures that all stakeholders, developers, designers, testers, and administrators have a common understanding of the system.

---

## Scope

GoTaxi is a complete ride-hailing platform for India.

The system allows users to:

- Book rides
- Become drivers
- Deliver parcels
- Schedule rides
- Make payments
- Track rides in real time
- Contact emergency services
- Earn rewards through referrals

The platform is designed to support future expansion into multiple mobility services.
