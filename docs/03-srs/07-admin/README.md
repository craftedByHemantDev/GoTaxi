# Overview

The GoTaxi Admin Panel is the central management system of the platform.

All platform operations are managed through this panel including users, drivers, rides, payments, pricing, reports, notifications, support, security and platform configuration.

The Admin Panel is developed using Laravel and is protected using Role Based Access Control (RBAC).

---

# Objectives

The Admin Panel shall allow administrators to:

- Monitor platform activity
- Approve driver applications
- Manage customers
- Manage rides
- Configure pricing
- Handle payments
- Monitor wallets
- View reports
- Send notifications
- Resolve disputes
- Configure application settings
- Manage permissions
- Audit system activity
