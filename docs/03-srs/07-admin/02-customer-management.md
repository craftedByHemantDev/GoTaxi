# Customer Management

Document ID: GT-ADM-002

Version: 1.0.0

Status: Draft

---

# Purpose

The Customer Management module enables administrators to monitor, manage, verify, and support all customer accounts on the GoTaxi platform.

---

# Features

- View all customers
- Search customers
- Filter customers
- View profile
- Suspend account
- Block account
- Delete account (Soft Delete)
- Restore account
- View ride history
- View wallet
- View referral history
- View complaints
- View emergency contacts
- Send notifications
- Reset customer account (Admin only)

---

# Customer List

Each customer record shall display:

- Customer ID
- Profile Photo
- Full Name
- Mobile Number
- Email Address
- Registration Date
- Total Trips
- Wallet Balance
- Referral Count
- Status
- Last Login

---

# Search

Search by:

- Name
- Phone Number
- Email
- Customer ID
- Referral Code

---

# Filters

- Active
- Suspended
- Blocked
- Deleted
- Verified
- Unverified
- City
- Registration Date
- Total Trips
- Wallet Balance

---

# Customer Details

The administrator can view:

Personal Information

Ride History

Payments

Wallet Transactions

Referral Details

Saved Addresses

Favourite Drivers

Support Tickets

Activity Logs

---

# Customer Actions

The administrator can:

Edit Profile

Suspend

Block

Restore

Send Notification

Add Wallet Balance

Deduct Wallet Balance

Generate Report

Export Data

---

# Security

Only authorized Admins can manage customer accounts.

Every administrative action must be stored in Audit Logs.
