# Purpose

The Dashboard provides a real-time overview of the GoTaxi platform.

It is the first screen displayed after an administrator logs into the system.

The dashboard shall display:

• Active Customers

• Total Drivers

• Online Drivers

• Pending Driver Approvals

• Total Rides

• Ongoing Rides

• Completed Rides

• Cancelled Rides

• Total Revenue

• Today's Revenue

• Monthly Revenue

• Wallet Balance

• Pending Withdrawals

• Active Coupons

• Referral Statistics

• Customer Support Tickets

• System Notifications

• Server Status
